# Preview scene inventory

`woodland.svg` and `station.svg` are original vector illustrations authored for
P05.1 and distributed under the repository [MIT License](../../../LICENSE).
No third-party artwork, font, external resource, raster input or image-generation
service is used. The SVG files are the editable originals and runtime exports.
They contain no baked labels, scripts or external references.

These are local illustrative environments for the Mosslight Trail and Silent
Relay shells, not imported pack media or authoritative location maps. Accessible
descriptions remain live in the story component. The complete local control/icon/
frame and item kit with QA-30 review is indexed in [UI sources](../ui/README.md).
Separate sample [portraits](../portraits/README.md) arrived in P05.3; persistent
campaign art and runtime generation remain P17.
