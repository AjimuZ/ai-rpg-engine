# Preview scene inventory

P05.1 and distributed under the repository [MIT License](../../../LICENSE).
No third-party artwork, font, external resource, raster input or image-generation
service is used. The SVG files are the editable originals and runtime exports.

Relay shells, not imported pack media or authoritative location maps. Accessible
descriptions remain live in the story component. The complete control/icon/frame,
portrait and item graphic kit and its QA-30 review remain P05.5; this inventory
