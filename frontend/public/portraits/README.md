# Preview portraits

`keeper.svg` and `attendant.svg` are original static vector portraits authored for
P05.3 under the repository [MIT License](../../../LICENSE). These editable sources
are also the runtime exports; no external artwork, fonts, services or inputs are
used. They contain no scripts, external references or baked labels.

Each portrait resolves from a stable public speaker ID inside its local preview.
Live names and role labels remain readable if artwork is absent or fails. Images
are decorative alongside that attribution; text-focused mode loads no artwork.
These illustrative identities are not imported or persisted campaign entities.
The complete graphic kit remains P05.5; runtime artwork and identity persistence
remain P17.
