# Credits

Original sample text and structured data by project contributors, 2026, first written as the cyberpunk test
fixture of the project (`backend/src/test/resources/packs/cyberpunk-neon-alley`). All files are covered by
LICENSE.md (MIT). No external assets, likenesses or third-party audio are included.

Music: `assets/alley-rain.wav` ("Neon Rain", 6-second loop) and `assets/alley-wires.wav` ("Humming Wires",
4-second loop) are original tracks rendered from note lists written in the script
`tools/sample-music/make-sample-music.mjs` of the project repository (no download, no sample library, no
third-party input). `presentation.json` declares them, with the adventure's mood policy, under `music`.
