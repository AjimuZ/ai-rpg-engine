Artwork: `assets/sword.png` is an original 96x96 icon drawn from geometry by the script
`tools/sample-art/make-sample-art.mjs` of the project repository (no download, no third-party input).
It is bound to the item `sword` by `presentation.json`.

Music: `assets/ford-dusk.wav` ("Ford at Dusk", 8-second loop) and `assets/ford-stones.wav` ("Stones in the
Current", 6-second loop) are original tracks rendered from note lists written in the script
`tools/sample-music/make-sample-music.mjs` of the project repository (no download, no sample library, no
third-party input). `presentation.json` declares them, with the adventure's mood policy, under `music`.
